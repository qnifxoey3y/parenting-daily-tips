# 趁着寒假，来挺拔身姿！温中西医寒假脊柱侧弯训练营将开班

> 更新时间：2026-09-16 (UTC+8)

近年来，

**青少年脊柱侧弯**

已成为继肥胖症、近视之后，

对青少年身心健康

构成严重威胁的第三大因素。

温州市中西医结合医院

运动医学中心

康复治疗师张淑益表示

治疗脊柱侧弯，

**抓住矫正黄金期至关重要，**

**尤其是女孩的11-13岁**

**男孩的12-15岁，**

否则孩子骨骼发育逐渐成熟，

矫正的空间也逐渐受限。

寒假临近**，温州市中西结合医院运动医学中心将启动脊柱侧弯寒假训练营**，为青少年儿童提供专业脊柱侧弯康复训练。

对于学业繁忙的孩子们，寒暑假无疑是宝贵的训练契机，可以充分利用这段时间进行短期集中锻炼，改善孩子的脊柱侧弯状况。

**训练营时间及地点：**

2025年1月-2月（节假日除外）周一至周五上午8:00-11:30 下午1:30-5:00。

温州市中西结合医院5号楼5楼运动医学中心。

**招生对象**

8-18岁特发性脊柱侧弯患者，并且能够坚持完成训练营训练课程。

**训练内容**

小班制开展训练课程，建议家长陪同参与，拍摄训练动作。

**主要训练内容如下：**

- 
脊柱侧弯体态评估，必要时需进行X光检查。

- 
个性化制订治疗方案。

- 
日常坐姿、站姿的矫正。

- 
正确的呼吸训练。

- 
德国施罗斯矫形体操训练。

**预约方式**

**1、关注“温州市中西医就医助手”。**

2、点击**“导诊→预约挂号→运动医学科→青少年脊柱侧弯筛查门诊”**，进行预约。

**报名须知**

1、请携带近期站立位脊柱全长X光片，如有矫形支具请佩戴。（若尚未拍X片先侧弯筛查门诊检查）

2. 训练时需穿运动服与运动裤，请勿穿裙子。

3. 训练前必须吃早餐、午餐避免低血糖

4. 训练时每个孩子限一名家长陪同，拍摄训练视频居家训练使用。
